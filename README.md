# Samara's Enchanted Invites

PROMPT COMPLETO PARA O LOVABLE



Crie uma loja virtual profissional chamada Samara Encanto Convites, especializada em convites digitais personalizados infantis.



O objetivo é que todo o processo seja automatizado, desde a escolha do convite até o recebimento do pedido, sem que eu precise conversar com o cliente.

EXPERIÊNCIA DO USUÁRIO



A navegação deve ser intuitiva e encantadora.



O cliente deve conseguir encontrar rapidamente o convite ideal usando categorias, filtros, pesquisa, vitrines e destaques.



Todo o processo de compra deve ser simples, rápido e agradável.



---



RESULTADO FINAL



Quero uma loja virtual extremamente profissional, rápida, bonita e moderna, voltada para o público infantil, com aparência premium.



O sistema deve permitir que eu administre tudo pelo painel (produtos, categorias, banners, páginas, preços e pedidos) sem precisar programar.



O cliente deve conseguir comprar sozinho, preencher todas as informações necessárias, pagar e concluir o pedido sem entrar em contato comigo.



Após a confirmação do pagamento, devo receber notificações instantâneas no painel, por e-mail e no WhatsApp com todos os dados da compra para produzir o convite e entregá-lo automaticamente ao cliente em até 24 horas.
